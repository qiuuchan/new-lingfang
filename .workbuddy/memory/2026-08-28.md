## 修 CI desktop-e2e 持续失败（commit a539f98，待 push + 验证）

- 小潘报「推送 github 出现好多 ci 失败」。经 GitHub Actions 公开 API（仓库 public，匿名可读 runs/jobs）排查：
  - **push 触发的 quality（typecheck+test）+ rust-tests（cargo test --workspace）全绿**，不阻塞开发
  - 失败的是 `desktop-e2e` job（nightly schedule + 手动 workflow_dispatch），都挂老 commit `1332823`
  - desktop-e2e 只在 schedule/dispatch 触发，push 不跑（ci.yml `if: workflow_dispatch || schedule`）
- 小潘贴的失败日志一锤定音：`runas 返回：exit=1 stdout= stderr=` → runas /trustlevel:0x20000 在 GitHub Actions 无交互桌面 runner 上**命令本身失败**，桌面壳压根没起。此前 5 个 commit（5d6b321→1332823）都在调 CDP 超时，方向错了——根因是 runas 在 CI 不可用，不是 CDP 配置
- **修法**：spawnElevated 重写，runas → Task Scheduler RunLevel=Limited（Chrome/Edge 安装器降权拉起浏览器的标准手法）：launcher.bat 注入 WEBVIEW2_* env + Register/Start-ScheduledTask + 进程轮询；cleanup/重启段注销 task + 删 launcher 避免残留；超时诊断加 LastTaskResult
- 已 commit a539f98（1 file +89/-13）。**沙箱无 tty 推不上去**，待小潘在 VSCode/Git Bash 终端 `git push origin main` 后，去 Actions 页手动 Run workflow 触发 desktop-e2e 验证
- 额外发现：annotations 报 Node.js 20 deprecated warning，actions（checkout/setup-node/pnpm action-setup @v4）被强跑 Node 24，建议后续升 @v5（不影响运行）
- 关键事实：GitHub Actions windows-latest runner 以 admin(elevated) 运行，WebView2 在 elevated 进程禁用 --remote-debugging-port（Chromium 安全限制），必须降权到 medium IL 才能开 CDP——这是 desktop-e2e 在 CI 的核心矛盾
