# 剪藏摘要（clip-digest）

读取系统剪贴板文本，将其作为「剪藏」持久化到宿主的 `storage.kv`，并调用灵坊平台 LLM（`llm.chat`）生成中文摘要，最终通过 `ui.view` 以宿主弹层展示结果。这是一个 `client` 运行时示例插件，运行于桌面壳内嵌的沙箱 iframe 中，只通过宿主注入的 `window.sdk` 调用宿主能力，本身不持有任何平台密钥或令牌。

## 能力说明与隐私影响

本插件在 `manifest.json` 中声明了 4 项能力，每一项的数据访问与隐私影响如下：

### 1. `clipboard`（读取剪贴板文本）
- **数据访问**：仅在用户点击「读取剪贴板并剪藏」按钮时，通过 `sdk.clipboard.readText()` 读取一次当前剪贴板文本内容。
- **隐私影响**：低。剪贴板内容可能为任意文本（如临时复制的链接、段落）。该文本仅用于本次剪藏与摘要，**不会**在未经 `llm.chat` 授权的情况下对外发送——且只在你主动触发时读取。若剪贴板为空则不做任何处理。

### 2. `storage.kv`（持久化剪藏）
- **数据访问**：通过 `sdk.storage.set('clip-digest:<时间戳>', { text, summary, createdAt })` 保存每条剪藏原文与摘要，按插件隔离命名空间存储。
- **宿主容量策略（需遵守）**：单个值上限 **256KB**，每个插件最多 **1024 个条目**。本插件每条记录仅保存原文 + 摘要 + 时间戳，体量很小；长文本剪藏仍建议避免超大段落以留足余量。
- **隐私影响**：低。数据存于本地宿主存储，与平台账号隔离，不会上传至第三方。仅在 `sdk.storage` 抛错时退化为 `localStorage` 安全网，作用域同样限定在插件 iframe 内。

### 3. `llm.chat`（灵坊平台 LLM 摘要）
- **数据访问**：将剪藏文本作为 `user` 消息、附系统提示「你是剪藏摘要助手，用简洁中文总结要点，分条列出，控制在200字内。」发送至灵坊平台 relay 的 `/llm/chat` 路由，默认模型 `fast`（180s AI 超时）。
- **密钥管理**：插件**不持有**任何 LLM API Key。请求由宿主侧的 LLM 桥接（`plugin_llm_bridge`）携带注入的 `LINGFANG_PLUGIN_BRIDGE_TOKEN` 代为转发，凭据对用户与插件均不可见。
- **隐私影响**：中。剪藏文本会离开本机发往平台 relay 以生成摘要。请避免剪藏包含密码、令牌等高敏信息的文本。
- **优雅降级**：当平台未配置 LLM 凭据时，宿主返回的错误消息包含 `relay_not_configured`。插件捕获该错误后**不抛出、不白屏**，仍保存原文剪藏，并以友好提示说明「AI 摘要暂不可用」，同时照常调用 `ui.view` 弹出降级说明。

### 4. `ui.view`（宿主弹层展示结果）
- **数据访问**：通过 `sdk.ui.render({ type: 'markdown', body })` 请求宿主以弹层/面板渲染摘要或降级说明。宿主侧仅渲染 Markdown 或 JSON，**不注入任意 HTML**，因此不会出现脚本注入风险。
- **隐私影响**：低。展示内容来自插件自身生成的摘要或固定提示文案，不外传数据。

## 运行

该插件为 `client` 类型，符合 v1 安装政策（本地导入第三方插件仅接受 `client` 运行时）。可通过 `lingfang-plugin build` 打包为 `.lfplugin` 后在灵坊工作台中加载，或作为桌面壳内嵌示例直接打开 `ui/index.html`（脱离宿主时 `window.sdk` 未注入，按钮将禁用并提示「当前运行环境未注入 SDK」）。
