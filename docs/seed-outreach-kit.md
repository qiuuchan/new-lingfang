## 0. 一句话定位（所有文案复用这句）

> 把散落在本机的 `.md` / `.txt` 文档收进一个**本地知识库**——自动切片、关键词全文检索、
> 带着检索片段向大模型提问。你的资料不出本机。（零服务器：无账号、无云端、纯本地桌面应用。）

## 3. 装机指引（发给种子用户时附上）

- 完整指引见 [`getting-started.md`](./getting-started.md)：`git clone` → `pnpm install` →
  `pnpm -C apps/desktop runtime:populate` → `pnpm dev:desktop`（首次约 3-5 分钟 + 1.7GB runtime）。
- **门槛提示（务必先说明）**：目前是源码安装，需要 Windows + Node 20 + pnpm 9 + Rust 工具链；
  只想直接装包的用户可等公开 Release（见 [`release-runbook.md`](./release-runbook.md)）。
- 首次跑通的验收动作：装好后点开「知识库工作站」→ 粘贴一段文本导入 → 搜索一个关键词命中 →
  提问（问答需在设置里配 relay 凭据，不配也能完成导入+检索，仅问答不可用）。
